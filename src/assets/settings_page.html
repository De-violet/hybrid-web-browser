Search Engine

Choose the main search engine, or use bang prefixes straight from the URL bar.

Default Search Engine
Active Search Engine

Bang Shortcuts in the Address Bar
Type these prefixes in the URL bar or the New Tab search box:
• !g kata kunci — Search Google directly
• !d kata kunci — Search DuckDuckGo directly
• !gh repo — Search repositories on GitHub
• !yt video — Search videos on YouTube
• !w topik — Search articles on Wikipedia
