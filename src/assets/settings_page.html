Mesin Pencari Default

Pintasan Bang di Address Bar
Ketik awalan berikut di URL bar atau kotak pencarian Tab Baru:
• !g kata kunci — Cari langsung di Google
• !d kata kunci — Cari langsung di DuckDuckGo
• !gh repo — Cari repositori di GitHub
• !yt video — Cari video di YouTube
• !w topik — Cari artikel di Wikipedia
